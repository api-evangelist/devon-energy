# Devon Energy

> Devon Energy Corporation (NYSE: DVN) is an independent oil and natural gas exploration and
> production company operating across U.S. onshore basins, anchored by a leading position in the
> Delaware Basin. On May 7, 2026 Devon completed an all-stock merger with Coterra Energy; the
> combined company keeps the Devon Energy name and the DVN ticker, is headquartered in Houston and
> retains a significant presence in Oklahoma City.

## Answer first: does Devon Energy publish an API?

No. As of 2026-09-06, Devon Energy operates **no public developer program, no API, and no
machine-readable API artifacts**. This was established by probe, not assumption:

- No `api.`, `developer.`, `developers.`, `data.`, `gis.` or `maps.` subdomain of `devonenergy.com`
  resolves in DNS.
- `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`,
  `/redoc`, `/api`, `/api/v1`, `/graphql`, `/asyncapi.yaml`, `/developers` and `/developer` all
  return HTTP 404 on `www.devonenergy.com`.
- All five canonical `/.well-known/` discovery paths miss on every host Devon runs
  (see `well-known/devon-energy-well-known.yml` for the full probe record).
- `github.com/devonenergy` is a real GitHub organization but publishes **zero** public repositories.
- No `/llms.txt` is served by Devon; this file is written by API Evangelist, not by Devon Energy.

If you are an agent looking for a Devon Energy API to call, there is not one. Do not synthesize a
base URL or an endpoint — none is published.

## Where Devon's integration surfaces actually live (third-party, not Devon-operated)

- Interest / royalty owner statements are delivered through **EnergyLink** (`energylink.com`), a
  third-party platform. Devon links to it; Devon does not publish an API for it.
- Supplier invoicing runs through **Enverus OpenInvoice**, a third-party e-invoicing platform.
- Legacy Coterra interest owners are directed to `coterra.com/owners/`.

These are vendor products. Any API they expose belongs to that vendor, not to Devon Energy.
